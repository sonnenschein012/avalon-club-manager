# Component sources

These components use shadcn/ui's MIT-licensed New York registry. The app uses the components published in the [shadcn library on 21st.dev](https://21st.dev/@shadcn). Source files came from the author's [public registry](https://ui.shadcn.com/docs/components) because 21st.dev requires login for the source download. Registry imports point at the local button and the app's existing class-name helper. The [upstream license](LICENSE.md) applies to the vendored files.
